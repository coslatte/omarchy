# Omarchy plugins

Version-controlled backup of the plugins installed in `~/.config/omarchy/plugins`.

## Install or update

```bash
git clone git@github.com:coslatte/omarchy.git
cd omarchy/plugins
./install.sh
```

The installer creates a dated backup of each plugin it replaces and rescans the shell. You can then enable and arrange widgets in `~/.config/omarchy/shell.json`.

The repository includes custom plugins and locally installed third-party plugins. Review their licenses and attribution before redistribution.
