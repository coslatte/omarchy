# Plugins de Omarchy

Copia de seguridad versionada de los plugins instalados en `~/.config/omarchy/plugins`.

## Instalar o actualizar

```bash
git clone git@github.com:coslatte/omarchy-plugins.git
cd omarchy-plugins
./install.sh
```

El instalador guarda una copia con fecha de cualquier plugin que vaya a reemplazar y vuelve a escanear la shell. Después puedes activar y ordenar los widgets desde `~/.config/omarchy/shell.json`.

El repositorio incluye plugins propios y plugins de terceros instalados localmente. Revisa sus licencias y atribuciones antes de redistribuirlos.
